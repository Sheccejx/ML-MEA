# SEED 三分类 EEG 情绪识别项目报告

## 1. 任务说明

本项目针对 SEED EEG 情绪识别数据完成三分类任务。输入为 EEG 片段，形状为 `62 x 400`，对应 62 个通道和 400 个时间点。类别标签为 `0/1/2`。官方数据包含训练集、验证集和只包含特征的测试集 `test_x_only.h5`。

最终提交文件为：

```text
submit/SEED.txt
```

该文件共 450 行，每行一个预测标签。

## 2. 数据检查

数据检查结果如下：

```text
train:      (900, 62, 400)
validation: (450, 62, 400)
test:       (450, 62, 400)
```

训练集和验证集标签均为三分类标签 `0/1/2`，类别数量均衡。测试集只包含 `X`，不包含标签。提交文件按照 `test_x_only.h5` 中样本的原始顺序生成。

对 train、validation 和 test 的全局标准差、样本标准差、通道标准差进行了检查。测试集与训练集、验证集的数值尺度接近，未发现 NaN/Inf 或明显的预处理异常。

## 3. 实验流程

实验大致分为以下阶段：

1. 原始 EEG 深度模型基线  
   尝试 CNN、EEGNet、MLP 等模型。由于样本量较小，模型容易过拟合，验证集表现不稳定。

2. 传统 EEG 特征  
   提取频带功率、统计量、通道特征等，使用 SVM、树模型等分类器。该路线稳定性较好，但单模型上限有限。

3. 特征扩展  
   加入 common average reference、通道统计特征、频带特征、协方差 PCA 特征等，提高特征表达能力。

4. 概率融合  
   保存多个候选模型在验证集和测试集上的预测概率，使用固定权重进行概率平均。最终提交采用该路线。

5. 稳健性检查  
   检查最终文件行数、标签范围、测试集 X 分布、预测类别分布和保守备选结果的一致性。

## 4. 最终模型

最终提交使用四个候选模型的预测概率加权融合：

|编号|主要特征与模型|说明|
|---|---|---|
|1|CAR + 统计/频带/协方差 PCA + HGB|主权重模型|
|2|CAR + channel z-score + 统计/频带 + MLP|补充非线性特征|
|3|CAR + 通道统计 + RandomForest|补充通道统计判断|
|4|CAR + 统计/频带/协方差 PCA + ExtraTrees|补充块级统计模型|

固定融合权重为：

```text
0.5222
0.1256
0.2907
0.0615
```

融合所需概率文件已保存在：

```text
probs/val/
probs/test/
```

这些概率文件只包含候选模型输出，不包含测试集标签。

## 5. 提交文件检查

最终提交文件：

```text
submit/SEED.txt
```

检查结果：

```text
行数: 450
标签范围: 0/1/2
类别分布: 0=190, 1=200, 2=60
```

`code/check_submit.py` 会重新调用 `code/final_fusion.py`，用包内概率文件再生成一次提交结果，并检查哈希是否一致。

## 6. 风险说明

最终结果使用了概率融合和块平滑候选模型，因此可能受到验证集结构的影响。测试集本身的 X 分布与验证集较接近，因此由输入数据尺度或预处理差异造成明显下降的风险较低。

主要不确定性来自验证集模型选择和块结构差异。如果测试集真实标签顺序与验证集存在明显差别，最终结果可能下降。为此保留 `submit/SEED_safe.txt` 作为保守备选。
